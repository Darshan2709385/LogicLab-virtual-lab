# LogicLab — DECO Virtual Lab

LogicLab is a browser-based learning project for exploring digital logic gates and binary adders. It is built with plain HTML, CSS, and JavaScript, so it does not require a framework or installation.

## Features

- Interactive AND, OR, NOT, NAND, NOR, XOR, and XNOR gate simulator
- Standard logic-gate symbols with live input and output indicators
- Half-adder and full-adder simulations
- Truth tables that update with the selected inputs
- Concept and Boolean formula display
- Responsive layout for desktop and mobile screens

## Open the project

### Standalone file

Open `LogicLab.html` in a modern web browser. It contains the HTML, CSS, and JavaScript in one file.

### Separate source files

Keep `index.html`, `style.css`, and `script.js` together in the same folder, then open `index.html` in a browser.
